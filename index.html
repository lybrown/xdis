xdis

An interactive, statically tracing 6502 disassembler.

Drop a binary (raw .bin/.rom/.mem, Atari .xex/.com, C64 .prg, .sap), an .xdis.json project, or .dop option files here.

Mark code with C, data with D, name things with N — the disassembly updates as you go. Press ? for all keys.
